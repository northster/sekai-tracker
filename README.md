# 세카이 기록 (Sekai Tracker)

프로젝트 세카이 결과 화면을 화면 캡처 + 기기 안 OCR로 읽어서 플레이 기록을 자동으로 남기는 안드로이드 앱. 갤럭시 Z 폴드(내부화면/커버화면)용.

- 화면 캡처(MediaProjection)만 쓰고 게임 데이터나 메모리는 건드리지 않음
- 글자 인식은 ML Kit(일본어/한국어 모델이 APK에 들어 있음)로 기기 안에서만 함. 인터넷 권한 없음

## 설치
[Releases](../../releases)에서 맨 위 `SekaiTracker.apk`를 폰에서 받아서 설치. `main`에 push할 때마다 GitHub Actions가 빌드해서 올림.
다른 브랜치는 Actions 실행 결과의 Artifacts에 APK가 있음.

## 쓰는 법
1. 앱에서 **시작** → 화면 캡처 허용 (오버레이 권한도 주면 결과 창이 뜸)
2. 게임을 하면 결과 화면에서 자동으로 기록되고, 화면 구석에 "정확도 / 이 곡 최고 / 갱신 여부"가 몇 초 보임
3. 인식이 애매하면 저장하지 않고 알림이 옴 → 눌러서 확인·수정 후 저장
4. 자동 감지가 불안정하면: 빠른 설정 패널에 **세카이 캡처** 타일을 추가해서 결과 화면에서 누르기 (설정에서 자동 감지를 끄고 타일만 써도 됨)
5. 이미 찍어 둔 스크린샷은 홈의 **스크린샷 가져오기**로 넣을 수 있음

## 화면 분석 (screenshots/)
| 파일 | 화면 | 쓰는 곳 |
|---|---|---|
| `result.jpg` | 결과 화면 | 기록. 곡 이름(왼쪽 위), 난이도 배지 + 楽曲Lv, スコア/ハイスコア, PERFECT~MISS(왼쪽 열), FULL COMBO 배너, COMBO, LATE/FAST(라벨 아래 숫자) |
| `song_select.jpg` | 곡 선택 | 오른쪽 패널의 곡 이름과 EASY~MASTER 레벨을 배워서 곡 이름 맞추기에 씀 |
| `live_prepare.jpg` | 라이브 준비 | 쓰지 않음 (곡 이름이 화살표에 가려짐) |

- 값은 고정 좌표가 아니라 **라벨 옆/아래의 숫자**로 찾음 → 폴드 내부/커버 화면, 레터박스(검은 띠)와 상관없이 동작
- 결과 화면 판별: PERFECT/GREAT/GOOD/BAD/MISS 라벨 중 4개 이상
- 검증: 풀콤보면 콤보 = 노트 수, FULL COMBO/ALL PERFECT 배너와 판정 개수 일치, FAST + LATE = GREAT + GOOD + BAD (샘플: 17 + 4 = 21). 안 맞으면 확인 요청
- LATE/FAST 중 하나를 못 읽으면 위 관계로 계산 (작은 흰 숫자 "4"는 데스크톱 OCR로도 놓쳤음)
- 점수의 회색 앞자리 0이 따로 읽혀도 이어 붙임

`app/src/test/resources/`의 OCR 결과(실제 스크린샷)로 파서 단위 테스트를 돌림. 기기에서는 **인식 테스트** 화면에서 샘플 결과 화면으로 ML Kit 정확도를 필드별로 확인할 수 있음.

## 데이터
기록은 폰 안(앱 전용 저장공간)에만 저장되고 앱에 인터넷 권한이 없음. 설정 → 데이터의 **백업 파일 만들기**로 기록·배운 곡·곡 이름 수정·설정을 JSON 파일 하나로 저장하고, **백업에서 불러오기**로 되살림(지금 기록에 더해지고 이미 있는 판은 건너뜀). 화면 이미지는 백업에 들어가지 않음.

## 배터리·발열
- 기본 1초 간격 (0.5~5초 설정)
- 확인할 때만 캡처 화면을 붙였다 떼서 평소엔 화면 미러링을 하지 않음
- 화면 왼쪽(결과 숫자 영역)의 작은 썸네일을 비교해서, **멈춰 있는 새 화면일 때만** OCR. 플레이 중엔 노트가 움직이니 OCR이 돌지 않음
- 화면 꺼지면 쉼, 선택: 게임이 앞에 있을 때만 확인(사용 정보 접근 권한)

## 정확도
판정별 가중치(기본 PERFECT 100 / GREAT 70 / GOOD 50 / BAD 0 / MISS 0 %)는 설정에서 바꿀 수 있고, 기록에는 판정 개수만 저장해서 바꾸면 지난 기록도 다시 계산됨. 곡·난이도별 최고, 평균, 최근 추이(최근 5판 평균 - 그 전 평균), 그래프, CSV 내보내기.

## 서명 키
`app/sekai-shared.keystore`는 이 앱 전용 서명 키(비밀번호는 `app/build.gradle.kts`에 있음). 모든 빌드가 같은 키로 서명돼서 업데이트가 덮어 설치됨.
저장소가 공개라면 다른 사람도 같은 키로 서명할 수 있으니, 원하면 `SEKAI_KEYSTORE_BASE64`, `SEKAI_KEYSTORE_PASSWORD`, `SEKAI_KEY_ALIAS` 시크릿으로 바꿀 수 있음(키가 바뀌면 한 번 지우고 다시 설치).
