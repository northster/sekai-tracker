# 세카이 기록 (Sekai Tracker)

프로젝트 세카이 결과 화면을 화면 캡처 + 기기 안 OCR로 읽어서 플레이 기록을 자동으로 남기는 안드로이드 앱. 갤럭시 Z 폴드(내부화면/커버화면)용.

- 화면 캡처(MediaProjection)만 쓰고 게임 데이터나 메모리는 건드리지 않음
- 글자 인식은 ML Kit(일본어/한국어 모델이 APK에 들어 있음)로 기기 안에서만 함
- 인터넷은 한글 곡명 찾기(본인 Gemini API 키를 넣었을 때만, 곡 이름만 전송)에만 씀

## 설치
[Releases](../../releases)에서 맨 위 `SekaiTracker.apk`. `main`에 push할 때마다 GitHub Actions가 빌드해서 `v0.1.N`으로 올림.

### Obtainium으로 자동 업데이트
1. [Obtainium](https://github.com/ImranR98/Obtainium) 설치
2. **앱 추가** → 소스 URL에 `https://github.com/northster/sekai-tracker` → **추가**
3. 처음 설치: 목록에서 세카이 기록 → **설치**. 이후 새 버전이 올라오면 Obtainium이 알려주고 눌러서 업데이트
- 다른 설정은 기본값 그대로 두면 됨 (릴리스는 정식 릴리스, APK는 하나뿐)
- 이미 브라우저로 설치했다면 2번 후 Obtainium이 설치된 버전을 알아봄. 서명이 같아서 덮어 설치됨

## 쓰는 법
1. 앱 홈의 **접근성 설정 열기** → 설치된 앱 → **세카이 기록** 켜기
   - 회색으로 막혀 있으면: 설정 → 애플리케이션 → 세카이 기록 → 오른쪽 위 ⋮ → **제한된 설정 허용** 후 다시 켜기 (브라우저로 받은 APK에 걸리는 안드로이드 보안 장치)
2. 이제 **프로세카를 켜면 자동으로** 게임 위에 작은 둥근 버튼이 뜨고, 게임을 끄거나 다른 앱으로 가면 사라짐. 화면 공유 허용도 필요 없음
   - 버튼은 끌어서 옮길 수 있음 (플레이 중 노트가 안 오는 곳에 두기)
   - **결과 화면**에서 누르기 → 기록 저장 + "이번 판 정확도 / 이전 최고 / 갱신 여부" 표시, 판정 개수 옆에 이전 최고 대비 +-
   - **곡 선택 화면**에서 누르기 → 그 곡의 난이도별 이전 최고 기록과 그 판의 판정 개수 표시
   - **라이브 준비 화면**에서 누르기 → 고른 난이도의 이전 최고 기록 표시 (곡 선택 화면에서 한 번 눌러 둔 곡 기준)
3. 인식이 애매하면 저장하지 않고 알림이 옴 → 눌러서 확인·수정 후 저장
4. 버튼 대신 빠른 설정 패널의 **세카이 캡처** 타일도 같은 동작
5. 이미 찍어 둔 스크린샷은 홈의 **스크린샷 가져오기**로 넣을 수 있음

- 기본은 **자동 인식**: 게임 중에만 2초마다 화면을 확인해서 결과·곡 선택 화면을 스스로 찾음. 설정에서 **버튼으로만**으로 바꾸면 떠 있는 버튼을 누를 때만 읽음
- 자동 실행이 안 되면: 설정 → 게임 앱에서 프로세카 패키지 이름 확인 (프로세카를 한 번 켰다 오면 '최근 앱'에 뜨니 눌러서 추가)
- 접근성 서비스를 쓰기 싫으면 홈의 **화면 공유로 시작** (이 경우 게임을 켜고 끌 때 따라가지 않고, 시작할 때마다 화면 공유 허용 필요)

접근성 서비스는 어떤 앱이 앞에 있는지와, 버튼을 누를 때(자동 방식이면 게임 중 일정 간격) 찍는 화면 사진만 씀. 게임 데이터·메모리나 다른 앱 내용은 읽지 않고 밖으로 보내지 않음.

## 화면 분석 (screenshots/)
| 파일 | 화면 | 쓰는 곳 |
|---|---|---|
| `result.jpg` | 결과 화면 | 기록. 곡 이름(왼쪽 위), 난이도 배지 + 楽曲Lv, PERFECT~MISS(왼쪽 열), FULL COMBO 배너, COMBO, LATE/FAST(라벨 아래 숫자). 점수는 읽지 않음 |
| `song_select.jpg` | 곡 선택 | 오른쪽 패널의 곡 이름과 EASY~MASTER 레벨. 곡 이름은 난이도 원들 바로 위에 왼쪽 정렬로 쌓인 줄(곡명·작곡가·Vo.) 중 맨 위 (자켓 그림 속 글자는 무시). 그 곡의 이전 최고 기록 표시 |
| `live_prepare.jpg` | 라이브 준비 | 난이도 배지만 읽음(곡 이름은 화살표에 가려져서 곡 선택 화면에서 읽은 곡을 씀). 그 난이도의 이전 최고 기록 표시 |

- 값은 고정 좌표가 아니라 **라벨 옆/아래의 숫자**로 찾음 → 폴드 내부/커버 화면, 레터박스(검은 띠)와 상관없이 동작
- 결과 화면 판별: PERFECT/GREAT/GOOD/BAD/MISS 라벨 중 4개 이상
- 검증: 풀콤보면 콤보 = 노트 수, FULL COMBO/ALL PERFECT 배너와 판정 개수 일치, FAST + LATE = GREAT + GOOD + BAD (샘플: 17 + 4 = 21). 안 맞으면 확인 요청
- 곡 이름을 못 읽었거나 처음 보는 이름이면 곡 이름 부분만 3배로 키워서 한 번 더 읽음. 그래도 못 읽으면 확인 화면에서 **곡 이름 다시 읽기**나, 같은 난이도·레벨 곡 / 최근 곡 목록에서 눌러서 고르기 (타이핑 필요 없음)
- LATE/FAST 중 하나를 못 읽으면 위 관계로 계산 (작은 흰 숫자 "4"는 데스크톱 OCR로도 놓쳤음)

`app/src/test/resources/`의 OCR 결과(실제 스크린샷)로 파서 단위 테스트를 돌림. 기기에서는 **인식 테스트** 화면에서 샘플 결과 화면으로 ML Kit 정확도를 필드별로 확인할 수 있음.

## 데이터
기록은 폰 안(앱 전용 저장공간)에만 저장됨. 인터넷은 한글 곡명 찾기에만 쓰고 기록은 보내지 않음. 설정 → 데이터의 **백업 파일 만들기**로 기록·배운 곡·곡 이름 수정·설정을 JSON 파일 하나로 저장하고, **백업에서 불러오기**로 되살림(지금 기록에 더해지고 이미 있는 판은 건너뜀). 화면 이미지는 백업에 들어가지 않음.

## 배터리·발열
- 버튼 방식(선택): 버튼을 누를 때만 화면을 한 장 찍어서 읽고, 그 사이에는 아무것도 하지 않음
- 자동 방식(기본, 2초): 1~5초 간격으로 화면을 한 장 가져오고, 화면 왼쪽(결과 숫자 영역)이 **멈춰 있는 새 화면일 때만** 글자 인식. 플레이 중엔 노트가 움직여서 글자 인식이 돌지 않음
- 화면 꺼지면 쉼, 선택: 게임이 앞에 있을 때만 버튼 표시·확인(사용 정보 접근 권한)

## 정확도
판정별 가중치(기본 PERFECT 100 / GREAT 70 / GOOD 50 / BAD 0 / MISS 0 %)는 설정에서 바꿀 수 있고, 기록에는 판정 개수만 저장해서 바꾸면 지난 기록도 다시 계산됨. 곡·난이도별 최고 기록(그 판의 판정 개수 포함), 정확도 그래프, CSV 내보내기.

- 결과 화면: 판정 개수 옆에 이전 최고 판과의 차이 표시 (`PERFECT 1166 -8`)
- 곡 선택 화면: 난이도별 최고 정확도와 그 판의 PERFECT~MISS
- 자켓: 결과 화면 왼쪽 위의 자켓을 잘라서 곡마다 저장, 목록과 곡 화면에 표시
- 결과 화면의 +- 표시는 결과 화면을 벗어날 때까지 남아 있음 (1.5초마다 화면이 바뀌었는지만 확인, 글자 인식 없음)
- 자켓: 결과 화면에서 자켓의 색 테두리를 직접 찾아서 그 안쪽만 자름
- **한글 곡명**: 설정 → 한글 곡명에 Gemini API 키를 넣으면 구글 검색으로 한국에서 가장 많이 쓰는 곡명을 찾아 표시 (곡 화면에서 직접 고칠 수도 있음)
- 곡 화면의 **나무위키**: 그 곡 문서를 바로 열기 (문서가 없으면 검색)
- 곡 화면의 **채보 보기**: sdvx.in 채보를 그 곡 이름으로 검색해서 열기 (앱에 인터넷 권한이 없어 사이트의 곡 번호를 알 수 없으므로 검색으로 연결)

## 서명 키
`app/sekai-shared.keystore`는 이 앱 전용 서명 키(비밀번호는 `app/build.gradle.kts`에 있음). 모든 빌드가 같은 키로 서명돼서 업데이트가 덮어 설치됨.
저장소가 공개라면 다른 사람도 같은 키로 서명할 수 있으니, 원하면 `SEKAI_KEYSTORE_BASE64`, `SEKAI_KEYSTORE_PASSWORD`, `SEKAI_KEY_ALIAS` 시크릿으로 바꿀 수 있음(키가 바뀌면 한 번 지우고 다시 설치).
